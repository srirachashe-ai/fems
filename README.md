# FEMS – Fire Extinguisher Management System

ระบบบริหารจัดการและตรวจสอบถังดับเพลิง เปิดผ่าน GitHub Pages เก็บข้อมูลใน Firebase
ทุกคนต้องเข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่านที่ผู้ดูแลสร้างให้ คนที่ไม่มีบัญชีอ่านหรือแก้ข้อมูลไม่ได้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บหลัก |
| `firebase-shim.js` | ตัวเชื่อมกับ Firebase และหน้าเข้าสู่ระบบ (ไม่ต้องแก้) |
| `firebase-config.js` | ค่าตั้งค่า Firebase และรายชื่อผู้ดูแล (`FEMS_ADMINS`) |
| `firestore.rules` | กฎสิทธิ์ของฐานข้อมูล (คัดลอกไปวางใน Firebase) |

## สิทธิ์ของแต่ละบัญชี

| | บัญชีผู้ตรวจ (รายแผนก) | บัญชีผู้ดูแล |
|---|---|---|
| ดูแดชบอร์ด ข้อมูลถัง ประวัติ | ได้ | ได้ |
| ตรวจถังและส่งผล | ได้ | ได้ |
| เข้าหลังบ้าน แก้ทะเบียน ลบ/แก้ผลตรวจ ติดตามข้อบกพร่อง | ไม่ได้ | ได้ |

## เพิ่มบัญชีผู้ใช้

Firebase console > **Authentication > Users > Add user**
- Email: `ชื่อผู้ใช้@fire-extinguisher-check-bdfff.firebaseapp.com` เช่น `prod@fire-extinguisher-check-bdfff.firebaseapp.com`
- Password: อย่างน้อย 6 ตัวอักษร
- ตอนเข้าสู่ระบบ พิมพ์แค่ชื่อผู้ใช้ เช่น `prod`

## เปลี่ยนรหัสผ่าน

- **เปลี่ยนรหัสของตัวเอง:** หลังบ้าน > ตั้งค่า > "เปลี่ยนรหัสผ่านของฉัน" ใส่รหัสปัจจุบันและรหัสใหม่
- **บัญชีผู้ตรวจ (เช่น `user`):** เข้าสู่ระบบด้วยบัญชีนั้นแล้วเปลี่ยนที่หน้าเดียวกัน หรือใน Firebase console > Authentication > Users > เลือกบัญชี > Reset password
- หลังเปลี่ยนรหัส เครื่องอื่นที่เข้าด้วยบัญชีนั้นอยู่จะยังเข้าได้จนกว่าจะออกจากระบบ ถ้าต้องการตัดทุกเครื่องทันที ให้ Disable แล้ว Enable บัญชีใน Firebase console

## เพิ่มผู้ดูแลระบบคนใหม่

1. สร้างบัญชีตามด้านบน เช่น `admin2`
2. แก้ `firestore.rules` เพิ่มอีเมลในรายการของ `isAdmin()` แล้วกด Publish ใน Firebase
3. แก้ `firebase-config.js` เพิ่มชื่อใน `FEMS_ADMINS` เช่น `["safety","admin2"]` แล้วอัปโหลดขึ้น GitHub

ทุกอีเมลในรายการผู้ดูแลต้องสร้างบัญชีไว้จริง อย่าปล่อยให้มีชื่อในรายการที่ยังไม่ได้สร้างบัญชี

## ข้อควรรู้

- **ปิดการสมัครเอง:** Authentication > Settings > User actions ต้อง **ไม่ติ๊ก** "Enable create (sign-up)" มิฉะนั้นคนนอกจะสร้างบัญชีเองได้
- **รหัสหลุดหรือพนักงานลาออก:** Authentication > Users > เลือกบัญชี > Reset password หรือ Disable account
- **เครื่องที่ใช้ร่วมกัน:** กด "ออกจากระบบ" มุมขวาบนทุกครั้ง ข้อมูลที่เครื่องจำไว้จะถูกล้าง
- **สำรองข้อมูล:** ส่งออก Excel และ PDF จากหลังบ้านทุกสิ้นเดือน
- **`firebase-config.js` ไม่ใช่รหัสลับ** ความปลอดภัยมาจากกฎใน `firestore.rules` และบัญชีผู้ใช้
